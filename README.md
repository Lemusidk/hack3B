# App 3B - Localizador Inteligente de Tiendas 🛒📍

Este proyecto fue desarrollado durante un **Hackathon** con el objetivo de optimizar la experiencia de usuario de los clientes de **Tiendas 3B**, ayudándoles a encontrar la sucursal más cercana y la ruta más eficiente.

## 🚀 Propuesta de Valor
La aplicación resuelve la dificultad de localizar tiendas de conveniencia en zonas de alta densidad, integrando herramientas de geolocalización en tiempo real.

## 🛠️ Stack Tecnológico
* **Frontend:** React.js, JavaScript (ES6+), CSS3.
* **Mapas:** Integración con API de Mapas para visualización de coordenadas.
* **Backend (En desarrollo):** Node.js & Express.
* **Base de Datos:** MongoDB (diseñada para almacenamiento geoespacial de sucursales).

## 📋 Características Principales
* **Geolocalización:** Identificación automática de la ubicación del usuario.
* **Buscador de Sucursales:** Filtrado de tiendas por proximidad.
* **Rutas Óptimas:** Cálculo de trayectos hacia la tienda seleccionada.

## 🏗️ Estructura del Proyecto
* `/src/components`: Componentes reutilizables de la interfaz (Busqueda, Mapa, Tarjetas).
* `/src/hooks`: Lógica para el manejo de la ubicación y estado.
* `/backend` (Próximamente): Estructura para la API REST con MongoDB.
